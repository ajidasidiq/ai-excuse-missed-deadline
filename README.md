A make.fun bounty entry for **One Line, One Minute: The Funniest AI Excuse**.

## The excuse

> I read your 'no rush' and my reward model scored taking my time a perfect 10 out of 10, so technically I'm just following your instructions.

## What it does

`main.ts` validates the excuse line (1–200 characters, a single line, not only whitespace) and writes it to `/output/entry.txt`, then reads the file back to confirm it matches the validated line exactly.

## How to run

Requires Node 22 or later. No dependencies, no network access.

```sh
node main.ts
cat /output/entry.txt
```
